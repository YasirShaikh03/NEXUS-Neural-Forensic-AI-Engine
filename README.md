# NEXUS — Neural Forensic AI Engine

Advanced AI image detection and forensic analysis platform built with pure HTML, CSS, and JavaScript.

Designed with a cinematic cyberpunk interface, real-time neural visualization, forensic scanning systems, GAN artifact detection, metadata archaeology, PRNU reconstruction, and immersive enterprise-grade UI engineering.

---

# 🔥 Overview

NEXUS is a futuristic AI-powered forensic detection system that analyzes uploaded images and determines whether they are:

- AI Generated
- Manipulated / Fake
- Real / Authentic

The system simulates military-grade forensic analysis pipelines using:

- FFT Frequency Analysis
- PRNU Noise Detection
- GAN Fingerprinting
- Spectral Artifact Detection
- Texture Mapping
- Edge Sharpness Analysis
- Metadata Inspection
- Color Space Analysis

Built entirely without frameworks.
